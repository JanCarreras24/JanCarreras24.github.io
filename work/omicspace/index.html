01 / TECHNICAL CHALLENGE

How can data from different sources be prepared, standardised and checked so that downstream analysis is consistent and reproducible?

02 / METHOD & PIPELINE

The work brings together preprocessing, integration, concept harmonisation and quality assurance. Common data structures make sources more comparable, while synthetic data and evaluation workflows support methodological development across collaborating teams.

  1. 01Prepare source data
  2. 02Harmonise concepts
  3. 03Check data quality
  4. 04Support analysis
03 / RESULTS & EVALUATION

The work supported the data foundations behind synthetic EHR and text-processing research, including the team’s OHDSI Europe 2026 contributions. It strengthened my experience with heterogeneous data and collaborative analytical workflows.

Evaluation scope

This describes my contribution within a collaborative platform. The associated research outputs provide evidence of the work; no platform-wide performance benchmark is claimed.

04 / MY CONTRIBUTION

I contributed to data preparation, integration and validation through the OmicSpace collaboration linked to Valencia, working in the PRBB research environment. This stage ended on 31 August 2026; I started a direct contract with Hospital del Mar on 1 September 2026.

05 / APPLICATION & TRANSFERABLE SKILLS

OmicSpace brings together multimodal biomedical data, with collaboration involving IIS La Fe and Hospital del Mar. OMOP provides a shared model for the clinical data component.

What this work demonstrates

Data pipelines, schema and concept harmonisation, quality controls, reproducible preprocessing and cross-team data integration.
